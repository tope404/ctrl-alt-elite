# CTRL+ALT+ELITE

**Interactive Group Portfolio Website**

---

## Overview

**CTRL+ALT+ELITE** is a responsive and interactive group portfolio website developed to introduce the members, personalities, interests, and shared experiences of a trio of Information Technology students. It serves as a digital representation of the group's identity, combining modern web design with object-oriented programming concepts.

The website features interactive member profiles, dynamically generated shared-interest comparisons, and an entertaining personality-based guessing game called **Who Among Us?**.

Developed by **BSIT 2D - Group 5 (Gel, Cy, and Tope)** as a final project requirement for **Object-Oriented Programming - IT Elec 2**.

---

## Key Features

* **Interactive Landing Page:** A visually engaging introduction to CTRL+ALT+ELITE, featuring the group's identity, introduction, and navigation to different sections.
* **Member Profiles:** Interactive member cards displaying individual information, personalities, interests, preferences, and personal goals.
* **Shared Interests:** Dynamically identifies and compares similarities and differences among members using the `SharedInterest` class.
* **Interest Filtering:** Allows users to filter results into All Matches, Shared (2+ Members), and Unique Traits categories.
* **Who Among Us?:** An interactive personality-based guessing game where users can reveal which member best matches a particular description and discover the reasoning behind each answer.
* **Responsive Design:** Adapts its layout and interface to different screen sizes and devices, including desktops, tablets, and mobile phones.
* **Interactive User Interface:** Features dynamic content rendering, interactive elements, and smooth navigation for an engaging browsing experience.
